# 公开说明与结果阅读原则

本仓库用于介绍 Jarvis-FootBall 的产品功能、使用方式与公开更新。生产系统的算法实现、公式参数、权重阈值、内部策略、Prompt 和数据集不在此发布。

## 如何阅读赛事分析

- 先确认比赛、开球时间及赛前、进行中或完赛状态。
- 留意资料来源、更新时间与缺失数据提示。
- 区分模型观点、AI 文字说明、机构报价和真实赛果。
- 查看历史表现时核对玩法、样本范围、时间段和结算口径。
- 分析结果存在不确定性；历史表现不代表未来结果。

## 教学材料的范围

仓库已有 `demo/` 是此前公开的独立教学示例。它不代表 V2.5 生产模型，不用于推导生产参数、验证生产实现或复现官网结果。

产品展示版本与具体模型的实现版本应分别理解，不能仅凭版本名称推断分析效果。
