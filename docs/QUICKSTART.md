# 快速开始

## 在线体验

访问 [Jarvis-FootBall 官网](https://www.jarvis-ai-club.com)，无需安装本地环境。

1. 打开 [赛事广场](https://www.jarvis-ai-club.com/#/aiFoot)，选择日期与比赛。
2. 进入详情，查看当前公开资料；会员内容按栏目显示权益提示。
3. 打开 [模型大厅](https://www.jarvis-ai-club.com/#/models)，浏览模块入口与历史表现。
4. 需要联赛、球队、球员或对阵资料时，使用 [全球赛事](https://www.jarvis-ai-club.com/#/data-center)。

功能开放状态、数据覆盖及账号权限以官网页面为准。

## 常见问题

**需要下载软件吗？**
网页即可访问。部分内容需要登录或相应会员权益。

**为什么某场比赛没有阵容、统计或情报？**
不同赛事与资料来源的覆盖范围、发布时间不同，请根据页面提示稍后查看或切换资料来源。

**在哪里看历史表现？**
可从模型大厅的历史记录或 [公开战绩](https://www.jarvis-ai-club.com/#/performance) 入口浏览。请核对样本范围、日期与统计口径。

**能在本地部署完整官网吗？**
此仓库用于公开展示与文档，不提供完整生产系统。已有 `demo/` 是历史教学示例，不代表 V2.5 的生产模型，也不能复现官网结果。

**如何反馈问题？**
文档与公开链接问题可提交 Issue；账号、会员或个人信息相关问题请使用 [官网联系入口](https://www.jarvis-ai-club.com/#/contact)。
